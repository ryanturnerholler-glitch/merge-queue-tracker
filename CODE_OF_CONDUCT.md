# Code of Conduct

Everyone taking part in this project, in issues, pull requests, discussions,
and reviews, is expected to be respectful and constructive. Disagree with
ideas, not people. Harassment, personal attacks, and discriminatory language
are not welcome here.

Maintainers may edit, hide, or remove contributions that break these
expectations, and may block repeat offenders. To report a problem, use the
private reporting route in [SECURITY.md](SECURITY.md) or email the maintainer
through their GitHub profile.

This is a condensed form of the
[Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/),
version 2.1, which applies in full.
